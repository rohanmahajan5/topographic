# Provider logos

Fetched 2026-11-05. Each file identifies the harness a column belongs to; the marks are the vendors'
trademarks. The page fills a monochrome file with the colour given here (simple-icons' brand hex for that icon, from
`data/simple-icons.json` on the `develop` branch); a file already in colour is drawn as it is.

## Connectors (MCP servers)

A connector's island and its blocks' glyph use `logos/<connector id>.svg` when it is here (the id is the server name in lower case, other characters as `-`). None is here yet: no connector logo has been fetched, and every connector is drawn as a lettered mark (its first letter on its harness's colour).
